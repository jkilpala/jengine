## Quick Start for Agents

Feed the LLM context file into your agent's system prompt:

```text
You are building a 2D game with jEngine.
Refer to the following API reference:

<jengine-context>
{contents of /ai/llm-context.md}
</jengine-context>
```

Or use the structured JSON spec for tool-calling agents:

```python
import json, urllib.request

spec = json.loads(
    urllib.request.urlopen("https://your-docs-host/ai/api-spec.json").read()
)

# List all available scripting functions
for fn in spec["functions"]:
    print(f"{fn['signature']}  — {fn['description']}")
```

## Key Concepts for AI

1. **Scripts** define `init(entity)` and `update(entity, dt)` — Lua (everywhere) or JavaScript (desktop).
2. **Lua calls the engine through namespaces** — `Transform.get_position`, `Input.is_action_pressed`;
   JavaScript uses the flat names. A package adds its own namespace (`Parallax.set`).
3. **All mutations are deferred** — `Transform.set_position`, `Entity.spawn_prefab`, etc. queue
   commands that apply after all scripts finish each frame.
4. **Scenes are JSON** (`"version": 2`) — entities with named components. Every sound a scene plays is
   listed in its `audio_refs`.
5. **Assets** (textures, audio, scripts) are referenced by path relative to `assets/`.
6. **Coordinates**: X-right, Y-up, origin at world center, rotation in radians; colours are linear.
