## Build Targets

`jengine` is the engine's CLI (`cargo run -p jengine-builder --bin jengine --`); see [Installation](/getting-started/installation/).

| Target | How | Status |
|--------|-----|--------|
| Windows | `jengine run <project>`, or the editor's Build panel | Native runtime and editor |
| Web | `jengine web-build <project>` | WebGPU, with a WebGL2 fallback |
| Android | `jengine android-build <project>` | APK / app bundle; Lua scripts only |
| Linux | `jengine linux-build <project>` | Builds and runs; tested under WSL only |
| macOS | `jengine macos-build <project>` | Builds and runs on Apple Silicon |
| iOS | `jengine ios-build <project>` | Runs on the simulator and an iPhone |

See [Cross-Platform](/architecture/cross-platform/) for what each platform can do.
