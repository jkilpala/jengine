## Using it

List it in the project's `project.jengine`, then rebuild the editor viewport
(`jengine viewport-build projects/<name>`):

```json
{
  "packages": [
    { "name": "{{PACKAGE_NAME}}", "source": { "type": "path", "path": "{{LINK_PATH}}" } }
  ]
}
```

A scene using its components must be a v2 scene (`"version": 2`).
